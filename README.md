# Customer Churn Prediction

A classification project that predicts whether a customer is likely to leave a service.

The dataset is generated locally, so the project can run without downloading a dataset.

## Objectives
- Prepare customer features
- Train a classification model
- Evaluate churn predictions
- Inspect important features

## Technologies
Python, Pandas, Scikit-learn

## Run
```bash
pip install -r requirements.txt
python train.py
```
